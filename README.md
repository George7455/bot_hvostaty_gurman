# Хвостатый гурман — редакционный Telegram pipeline

Сервис автоматически готовит посты по контент-плану, но ничего не публикует без одобрения редактора.

## Как это работает простыми словами

1. В 09:00, 15:00 и 21:00 по Москве сервис берёт первую свободную тему из Google Sheets.
2. Строка получает `IN_REVIEW`, AI готовит черновик, а редактор получает его в Telegram.
3. Редактор выбирает: одобрить, переписать или переписать с замечаниями.
4. Каждая версия хранится отдельно. Кнопка относится именно к той версии, рядом с которой она показана.
5. После одобрения фиксированный текст отправляется в канал, затем строка таблицы получает `PUBLISHED`.
6. Команда `/upload` позволяет тем же способом адаптировать текст или PDF вручную.

## Требования

- Node.js `>=20.16 <21` или `>=22.3`;
- PostgreSQL;
- Telegram bot и канал;
- Google service account с доступом к таблице;
- OpenAI API key или совместимый AI proxy;
- Telegraph access token для публикаций длиннее 2200 символов.

## Google Sheets

Обязательные заголовки:

- `content_id` — уникальный, непустой и неизменяемый идентификатор материала;
- `topic`;
- `rubric`;
- `status`.

Строки можно сортировать и перемещать: обновление выполняется по `content_id`, а не по запомненному номеру строки.

## Настройка

Скопируйте `.env.example` в `.env` и заполните значения. Для группового чата обязательно задайте `TELEGRAM_MODERATOR_USER_IDS`: это ID людей, которым разрешены `/upload`, `/tick` и кнопки модерации. `TELEGRAM_MODERATOR_CHAT_IDS` задаёт разрешённые личные/групповые чаты.

Проверки без внешних запросов:

```bash
npm ci
npm run prisma:generate
npm test
npx prisma validate
```

## Миграции

Для новой пустой БД:

```bash
npm run prisma:migrate:deploy
```

Если старая БД была создана через `prisma db push` и таблицы уже существуют, сначала сделайте резервную копию и пометьте только начальную миграцию как применённую:

```bash
npx prisma migrate resolve --applied 20260317000000_initial
npm run prisma:migrate:deploy
```

Не выполняйте `migrate resolve` на пустой БД.

## Запуск

```bash
npm run build
npm start
```

Ручной запуск одного планового шага:

```bash
npx tsx manual-tick.ts
```

## Если операция требует сверки

`NEEDS_RECONCILIATION` означает, что после сетевой ошибки нельзя доказать, был ли принят запрос Telegram/Telegraph. Автоматического повтора нет специально, чтобы не создать дубль. Сначала проверьте канал или модераторские чаты, затем исправьте состояние операции вручную по фактическому результату.
